# sysdes

**sysdes** — проект инструмента для проектирования и разбора архитектуры систем. Его основа — визуальный редактор, в котором на одном холсте можно сочетать элементы HLD, логической ER-модели и sequence-сценариев, добавлять текст решения и экспортировать результат в JSON, SVG или PNG.

Этот репозиторий — **публичный срез проекта**, а не полный исходный код развёрнутого приложения.

## Что здесь есть

- [`frontend/`](frontend/) — редактор на React, TypeScript, Vite, React Flow и Zustand; исходный код и unit-тесты.
- [`contracts/`](contracts/) — OpenAPI, JSON Schema и примеры данных для формата холста, экспорта и оценки решений.
- [`docs/sdd/`](docs/sdd/) — требования, архитектурные решения, модель холста, сценарии оценки, API и критерии приёмки.

Спецификации описывают целевую систему, в том числе серверное сохранение и AI-оценку. Наличие функции в SDD не означает, что она доступна в этом публичном срезе.

## Запуск frontend

Требуются Node.js 24 LTS и pnpm 11.

```sh
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend dev
```

Откройте <http://127.0.0.1:5173>. Пример смешанного холста доступен по адресу <http://127.0.0.1:5173/?fixture=standard>.

Проверки frontend:

```sh
pnpm --dir frontend test
pnpm --dir frontend build
```

Подробнее о редакторе — в [frontend/README.md](frontend/README.md), о проектных требованиях и контрактах — в [docs/sdd/README.md](docs/sdd/README.md).

## Границы публикации

Backend, конфигурация развёртывания и вспомогательные скрипты здесь не опубликованы. Поэтому полный сценарий с серверным API из этого репозитория не запускается. Часть ссылок в SDD ведёт на материалы полного проекта, которых нет в публичном срезе. Команда `test:e2e` из frontend также требует отсутствующий здесь корневой `playwright.config.ts`.
