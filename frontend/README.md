# sysdes — прототип редактора

Первый этап [плана реализации](../docs/superpowers/plans/2026-09-06-sysdes-mvp.md). Смешанный холст HLD / ER / Sequence, локальное редактирование текста и экспорт JSON / SVG / PNG. Учётные записи, серверное сохранение и AI-оценка относятся к следующим этапам.

## Запуск

Node.js 24 LTS и pnpm 11:

```sh
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend dev
```

Открыть http://127.0.0.1:5173. Стандартная нагрузочная сцена: `/?fixture=standard`.

## Проверки

```sh
pnpm --dir frontend test
pnpm --dir frontend build
pnpm --dir frontend exec playwright install chromium firefox
pnpm --dir frontend test:e2e
```

Браузерные проверки запускаются из корня репозитория указанной командой. Первый запуск Playwright скачивает браузеры. Отчёт и снимки сохраняются в `.spec-work/` и не входят в Git.

## Границы прототипа

- CanvasDocument остаётся независимым от React Flow; исходная семантика примера берётся из SDD fixture. Начальная геометрия явно адаптирована для демонстрации.
- Текстовый черновик принадлежит отдельному полю. Blur / Enter фиксирует изменение, экспорт ожидает завершения композиции и выполняет общий flush. Многострочный Enter сохраняет перевод строки.
- SVG генерируется из документа и не содержит HTML, скриптов или внешних ресурсов. JSON сохраняет полный документ. PNG растеризуется из того же SVG; для изображений более 8192 пикселей по стороне или 32 миллионов пикселей выводится ошибка с предложением использовать SVG.
- Экспорт сохраняет содержание и геометрию, но не является снимком DOM: шрифт Arial/system fallback, многострочный текст разворачивается целиком. Точная идентичность экранному оформлению не является результатом этого этапа.
- Счётчики и профилирование доступны только в development-сборке. Продуктовая аналитика и отправка телеметрии отсутствуют.

Причины локального состояния и мемоизации описаны в [спецификации ввода](../docs/sdd/12-input-isolation.md) и [документации React Flow](https://reactflow.dev/learn/advanced-use/performance).

Исходный смешанный пример включён в репозиторий приложения (`src/model/mixed.json`), поэтому сборка не требует соседнего Git-репозитория документации. Источник примера: baseline документации e18e5d9.
